╭────────────────────── S1  Honest audit: all phases, ACCEPT, result compared with the plaintext ──────────────────────╮
│ Hospital EHR access log. An insider (staff 417, night shift) exports patient records in a burst. The cloud stores    │
│ the encrypted log. An auditor asks: how many EXPORT_RECORDS actions, and how many patient records in total? The      │
│ answer must come with proofs the auditor can check.                                                                  │
│                                                                                                                      │
│ Honest labels: the blockchain is an in-process simulation (4 validators, no network); STARK proofs are plain mode,   │
│ not zero-knowledge; all timings are from this laptop, one run.                                                       │
