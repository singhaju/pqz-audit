╭──────────────────────────────────────────────────────── PQZ-Audit demo ────────────────────────────────────────────────────────╮
│                                                                                                                                │
│  Story: a hospital keeps its EHR access log in the cloud, encrypted. An insider (staff 417) exports patient records in a       │
│  burst. The auditor must find out, without the cloud being trusted.                                                            │
│                                                                                                                                │
│  Main question (question 1 in the menu): how many EXPORT_RECORDS actions (action = 7) happened in this epoch, and how many     │
│  patient records did they export in total? In query terms: COUNT and SUM(patients) where action = 7.                           │
│  Each log record has four fields: action (what was done, a code 1-7), patients (how many patient records it touched),          │
│  department and staff id.                                                                                                      │
│  So action = 7 means "bulk export of patient records". The action codes:                                                       │
│                                                                                                                                │
│    code   action             meaning                                patients touched         an auditor may ask about          │
│   ──────────────────────────────────────────────────────────────────────────────────────────────────────────────────────────   │
│    1      VIEW_CHART         open and read one patient's chart      1-3 (sometimes 20-79:    snooping on a famous patient      │
│                                                                     a ward list)                                               │
│    2      EDIT_CHART         change a chart (notes, vital signs)    1                        who changed a record              │
│    3      PRINT              print a record on paper                1-2                      paper copies leaving the          │
│                                                                                              hospital                          │
│    4      LOGIN              start a session                        0 (no patient touched)   logins at odd hours               │
│    5      LOGOUT             end a session                          0                        session length                    │
│    6      ORDER_MEDICATION   order a drug for a patient             1                        drug misuse                       │
│    7      EXPORT_RECORDS     download many patients' records to a   2-29 or 150-899          data theft (our story: only       │
│                              file                                                            staff 417)                        │
│                                                                                                                                │
│  Log: N = 10,000 records, 20 blocks of 500.                                                                                    │
│                                                                                                                                │
│  Honest labels: blockchain = in-process simulation (4 validators, no network); STARK proofs = plain mode, not zero-knowledge;  │
│  timings = this laptop, one run.                                                                                               │
│                                                                                                                                │
│  How to use: one audit menu below. Questions 1-10 are the normal cases and every one shows Phases 1-7 (question 1 in full,     │
│  the others as a one-screen recap). Questions 11-15 add another proved action, the attacks, and your own query. The menu       │
│  comes back after every answer.                                                                                                │
│                                                                                                                                │
