╭────────────────────────────────────────────────── Query syntax and examples ───────────────────────────────────────────────────╮
│  How to write a query  (like a SQL WHERE clause, conditions joined by AND)                                                     │
│    action = 7         action code 1-7 or a name (7 = EXPORT)                                                                   │
│    staff = 417        staff id                                                                                                 │
│    dept = 500         department: 101 ER, 118 ICU, 140 Admissions/Records, 205 Oncology, 220 Radiology, 310 Pharmacy, 330      │
│  Laboratory, 500 Psychiatry (or its name)                                                                                      │
│    patients >= 101    patients touched; operators =, >=, >, <=, <                                                              │
│  Short form also works: a=7, d=417, c=500, bmin=101, bmax=100 (comma = AND).                                                   │
│  OR is not in this box: compound OR queries are shown with  bash demo/demo.sh --scenario search                                │
│                                                                                                                                │
│  Every answer gives COUNT (how many records), SUM (total patients touched) and AVG (SUM / COUNT, patients per record).         │
│  Examples to copy are in the table below.                                                                                      │
│                                                                                                                                │
│  Leave a condition out to mean 'any'. The answer is checked against the plain log. Search layer only: for a proved answer use  │
│  question 1, 9, 10 or 11.                                                                                                      │
