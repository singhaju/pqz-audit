What it does

The demo audits 10,000 encrypted log records and returns a verified count and sum without the auditor or the requester seeing any plaintext. It runs the real code path (w35, --fmt p2r): make records, encrypt them, prove them, anchor an epoch, prove access and query, then verify. Everything runs in one process.

What it contains

  • Five actors are drawn, because the program plays five: the log provider (LP), the cloud (CSP), the auditor (AA), the ledger, and the requester. In this demo the requester is the TPA, and the "auditor check" is the AA's aa_finalize.

  • Real totals for N = 10,000: 20 blocks of 500, 5 chunks of 4 blocks, query result count 100 and sum 78,435,187; the requester receives 288,118 bytes (block list 2,580 + openings 6,048 + run proofs 153,261 + auth proof 126,213).

/// Generate `n` records, of which exactly `sigma_count` satisfy P1..P4.
///
/// Records are ordered by `ts == id`. `layout` decides where the hits are.
pub fn r#gen(n: usize, sigma_count: usize, layout: Layout, seed: u64) -> Vec<Record> {
    assert!(sigma_count <= n, "sigma_count must not exceed n");
    let mut rng = ChaCha20Rng::seed_from_u64(seed);

    let mut records: Vec<Record> = (0..n)
        .map(|i| {
            let id = i as u64;
            Record {
                id,
                ts: id,
                a: non_hit_excluding(&mut rng, A_DOMAIN, X),
                b: rng.next_u32() & (B_DOMAIN - 1),
                c: non_hit_excluding(&mut rng, A_DOMAIN, Z),
                d: uniform_below(&mut rng, A_DOMAIN),
            }
        })
        .collect();

    let hit_ids = match layout {
        Layout::Clustered => {
            let offset = uniform_below(&mut rng, (n - sigma_count + 1) as u32) as usize;
            (offset..offset + sigma_count).collect::<Vec<_>>()
        }
        Layout::Scattered => {
            let mut ids: Vec<usize> = (0..n).collect();
            for i in 0..sigma_count {
                let j = i + uniform_below(&mut rng, (n - i) as u32) as usize;
                ids.swap(i, j);
            }
            ids.truncate(sigma_count);
            ids
        }
    };

    for idx in hit_ids {
        let r = &mut records[idx];
        r.a = X;
        // B_DOMAIN - Y is a power of two (2^19), so masking is unbiased.
        let span = B_DOMAIN - Y;
        r.b = Y + (rng.next_u32() & (span - 1));
        r.c = uniform_below(&mut rng, Z);
        r.d = W;
    }

    records
}

What it does

Each record is encrypted on its own with AES-256-GCM. The key comes from the master key and the record id, so a leak of one key does not open other records. The LP also adds 45 keyed hash tags that let the cloud find a = 7 without reading anything. The Merkle leaf commits to id, ciphertext and tags.

  • Tag count 45 = a equality (1) + b prefixes (21) + c equality and prefixes (1 + 21) + d equality (1).
  • Decrypt check passes only with the key.

/// Per-record key: `HKDF-SHA3-256(master, "rec" || id_le)`.
fn record_key(master: &[u8; 32], id: u64) -> [u8; 32] {
    let hk = Hkdf::<Sha3_256>::new(None, master);
    let mut info = [0u8; 11];
    info[..3].copy_from_slice(b"rec");
    info[3..].copy_from_slice(&id.to_le_bytes());
    let mut key = [0u8; 32];
    hk.expand(&info, &mut key).expect("32 bytes is a valid HKDF length");
    key
}

/// GCM nonce. The record key is unique per id and the nonce is the id itself,
/// so (key, nonce) is never reused; uniqueness does not depend on a counter
/// staying alive across restarts.
fn nonce_for(id: u64) -> [u8; 12] {
    let mut n = [0u8; 12];
    n[..8].copy_from_slice(&id.to_le_bytes());
    n
}

fn aad_for(id: u64, ts: u64) -> [u8; 16] {
    let mut aad = [0u8; 16];
    aad[..8].copy_from_slice(&id.to_le_bytes());
    aad[8..].copy_from_slice(&ts.to_le_bytes());
    aad
}

/// AEAD-encrypt the four attributes of a record. Timed separately in
/// `exp1_construction`.
pub fn aead_encrypt(keys: &EpochKeys, r: &Record) -> Vec<u8> {
    let cipher = Aes256Gcm::new_from_slice(&record_key(&keys.master, r.id)).expect("256-bit key");
    let nonce_bytes = nonce_for(r.id);
    let nonce = Nonce::<Aes256Gcm>::try_from(&nonce_bytes[..]).expect("96-bit nonce");
    let aad = aad_for(r.id, r.ts);
    let mut pt = [0u8; 16];
    pt[..4].copy_from_slice(&r.a.to_le_bytes());
    pt[4..8].copy_from_slice(&r.b.to_le_bytes());
    pt[8..12].copy_from_slice(&r.c.to_le_bytes());
    pt[12..].copy_from_slice(&r.d.to_le_bytes());
    cipher
        .encrypt(
            &nonce,
            Payload {
                msg: &pt,
                aad: &aad,
            },
        )
        .expect("AEAD encryption")
}

/// The tags stored for one record: equality tags for a, c, d and prefix tags
/// for b and c (45 tags). Sorted so `rps_eval` can binary-search.
pub fn tags_for_record(r: &Record, key: &TagKey) -> Vec<Tag> {
    let mut tags = Vec::with_capacity(45);
    tags.push(eq_tag(key, ATTR_A, r.a));
    tags.extend(prefix_tags(key, ATTR_B, r.b));
    tags.push(eq_tag(key, ATTR_C, r.c));
    tags.extend(prefix_tags(key, ATTR_C, r.c));
    tags.push(eq_tag(key, ATTR_D, r.d));
    tags.sort_unstable();
    tags
}

/// Merkle leaf: `SHA3(0x00 || id || ciphertext || tags...)`.
pub fn leaf_hash(r: &EncryptedRecord) -> [u8; 32] {
    let mut parts: Vec<&[u8]> = Vec::with_capacity(3 + r.tags.len());
    let id = r.id.to_le_bytes();
    parts.push(&[0x00]);
    parts.push(&id);
    parts.push(&r.ciphertext);
    for t in &r.tags {
        parts.push(t);
    }
    sha3_parts(&parts)

What it does

R_RC proves that the encrypted records the cloud holds are the ones the LP committed to: block fields, tag lists and headers are absorbed into a Poseidon2 sponge. The stream is cut into chunks, and every chunk gets its own STARK proof, so chunks can be proven and checked independently.

What it contains

  • Chunk public values include s_in, s_out, chunk index, hdr_first, and the check values alpha, beta, acc.
  • Real N = 10,000 run: 5 chunk proofs, 5,120 trace rows, 837,561 bytes, 127 conjectured bits (49 unique-decoding, 73 list-decoding).

//! w38 stage 3: R_RC over linked chunks of the PACKED stream (two records per absorbed word) with range checks.
//!
//! Port of `chunk.rs` (w35 D1/D1b/D1c) to the packed format of `pair.rs`. The row kinds are the countdown of `pair.rs`
//! (hdr / va / vb, rem, zr, rinv; pad = seen - last), so the old K = (pid, e, seq) columns are gone: pid and e live in the header
//! word, seq = seq_start + position. A single RC proof (the w33 `rc.rs` role) is ONE chunk with `chunk_index = 0` that holds all
//! blocks (the verifier then knows the whole final state, whose first 4 elements are the stream digest); there is no separate AIR.
//!
//! Packed word (record row): [id_a, v_a, b_a, tag_a, id_b, v_b, b_b, tag_b]; header row: [e, g, m_g, pid, seq_start, hd_lo, hd_hi, 1].
//! Rows per block: 1 + ceil(B/2). Public values: `ChunkLayout` (46), `total_words` and the chunk size count PACKED words.
//!
//! Constraints (degree <= 3):
//!   R1/R2/R2b  Poseidon2 per row, sponge from the public s_in (chunk 0: s_in = IV(total_words)).
//!   R3  row 0: word = hdr_first (public), a header row; hdr counter = hdr_before + 1.
//!   R4  row kinds, countdown, empty half b holds the all-zero half word (so its tag, v, b are 0).
//!   R5  counter hn' = hn + hdr'.  Last real row: zr = 1 (block complete), hn = hdr_before + n_blocks_chunk, out = s_out.
//!   R6  idx / last / seen as in `pair.rs`.
//!   D1  three accumulators binding BOTH tags of a record row with distinct powers of alpha, and the header slots 0..6 with powers of beta:
//!         row 0 / transition:  acc' = alpha^2 acc + (1-hdr') (alpha tag_a' + tag_b') + hdr' sum_{i<7} beta^i w_i'
//!       (an empty half contributes tag 0). Read at row `last`.
//!   RANGE  (w38 stage 3) for every row with va = 1: v_a, v_b < 2^32 and b_a, b_b < 2^20, by bit columns (32 + 20 per half).
//!       The empty half is covered too: its word is forced to zero, so its bits are zero. This is what makes Exec P2r sound.
//! Padding rows are outside every structural rule (pad = seen - last) and are not read by any boundary constraint.

/// Verify a block against the epoch keys: record count, summary digest, Merkle
/// root and header signature. Any changed leaf or header field fails.
pub fn verify_block(block: &Block, keys: &EpochKeys) -> Result<(), String> {
    if block.header.count as usize != block.records.len() {
        return Err("record count does not match header".into());
    }
    let summary = Bloom::build(
        block.records.len(),
        block.records.iter().flat_map(|r| r.tags.iter()),
    );
    if summary.digest() != block.header.summary_digest {
        return Err("summary digest mismatch".into());
    }
    let leaves: Vec<[u8; 32]> = block.records.iter().map(leaf_hash).collect();
    if merkle_root(&leaves) != block.header.merkle_root {
        return Err("Merkle root mismatch".into());
    }
    if !keys.verify(&block.header.to_bytes(), &block.signature) {
        return Err("header signature invalid".into());
    }
    Ok(())
}

//! simulated ledger (signed transactions, block execution on every validator, QC).
//!
//! Attack classes (variants in brackets):
//!   1. replay of a consumed RID_Q   [replay_consume, reauthorize_after_consume, consume_unauthorized]
//!   2. wrong canonical state Omega_e [wrong_omega_flipbit, wrong_omega_other_epoch,
//!                                     wrong_omega_forked_policy, stale_epoch_current]
//!   3. predicate changed after authorization [predicate_changed]
//!   4. authenticated block omitted  [omit_block, forged_shorter_epoch]
//!
//! One "trial" = one attack transaction (or one forged response) with its own RID,
//! committed in batches of up to 100 per block; trials do not share RIDs, so they are
//! independent. Each variant also runs the matching honest operation as a CONTROL, so a
//! harness that rejects everything would be caught (control_ok must equal trials).
//! The attacker is a registered submitter (it holds a valid transaction key); transaction
//! signatures therefore do not stop it, only the contract rules and the verifier do.
//!
//! Mutation testing: with the `mutation` feature (or in unit tests) one defence at a time

fn mutate(w: &Workload, kind: &str, r: &mut Rng) -> Workload {
    let mut m = w.clone();
    match kind {
        "changed_record_word" => {
            let i = rec_index(w, r);
            let j = below(r, 7); // pid, epoch, seq, id, v, b, tag (never the flag)
            let x = m.words[i][j];
            m.words[i][j] = match j {
                4 => x ^ (1u64 << below(r, 32)),
                5 => x ^ (1u64 << below(r, 20)),
                _ => fadd(x, delta(r)),
            };
        }
        "dropped_record" => {
            let i = rec_index(w, r);
            m.words.remove(i);
        }
        "duplicated_record" => {
            let i = rec_index(w, r);
            let x = m.words[i];
            m.words.insert(i, x);
        }
        "reordered_records" => {
            let i = rec_index(w, r);
            let mut j = rec_index(w, r);
            while j == i || m.words[i] == m.words[j] {
                j = rec_index(w, r);
            }
            m.words.swap(i, j);
        }
        "changed_block_header" => {
            let g = below(r, w.n_blocks);
            let j = below(r, 5); // e, g, m_b, pid, seq_start
            let i = g * (w.block_size + 1);
            m.words[i][j] = fadd(m.words[i][j], delta(r));
        }
        _ => panic!("unknown mutation {kind}"),
    }
    m
}
